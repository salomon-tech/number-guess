🧠 Jeu de Devine-Nombre
Un simple jeu de console en Python où l'utilisateur doit deviner un nombre aléatoire choisi par l'ordinateur entre 0 et 10.

✨ Fonctionnalités
Jeu de devinettes classique : L'ordinateur pense à un nombre, et vous essayez de le deviner.

Indices : Le jeu indique si votre proposition est trop élevée ou trop basse.

Compteur de tentatives : Il garde la trace du nombre d'essais nécessaires pour trouver le bon nombre.

Option de rejouer : Après avoir trouvé le nombre, vous pouvez choisir de recommencer une nouvelle partie.

Gestion des erreurs : Le jeu gère les entrées non numériques pour éviter les plantages.

🚀 Comment jouer
Prérequis
Assurez-vous d'avoir Python installé sur votre machine.

Exécution
Enregistrez le code fourni dans un fichier nommé, par exemple, devine_nombre.py.

Ouvrez votre terminal ou invite de commande.

Naviguez jusqu'au répertoire où vous avez sauvegardé le fichier.

Exécutez le jeu avec la commande :

Bash

python main.py
Instructions en jeu
Le jeu vous demandera votre nom d'utilisateur.

Entrez votre proposition de nombre lorsque vous y êtes invité (entre 0 et 10).

Le jeu vous indiquera si le nombre est plus grand ou plus petit que votre proposition.

Continuez jusqu'à ce que vous trouviez le bon nombre !

Une fois le nombre trouvé, vous aurez la possibilité de continuer (y) ou de quitter (n).
